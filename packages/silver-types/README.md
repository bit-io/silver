# @hackeros/silver-types

Typy TypeScript dla `window.silver` — silnika HTML/CSS/JS [Silver](https://github.com/HackerOS-Linux-System/silver) (H#/Bit, bez WebView).

```sh
npm i -D @hackeros/silver-types
```

```json
{ "compilerOptions": { "types": ["@hackeros/silver-types"] } }
```

```ts
const info = await window.silver.info();
```

Publikacja i wersjonowanie: [docs/npm.md](../../docs/npm.md).
